```
1. Download FileZilla

3. Upload file-file ke /public_html/
```

## 🚨 COMMON ISSUES - QUICK FIXES

| Masalah | Solusi | Guide |
|---------|--------|-------|
| **Blank page** | Check `storage/logs/laravel.log` | Troubleshooting |
| **500 Error** | Set APP_DEBUG=true untuk lihat error | Troubleshooting |
| **Database error** | Verify credentials di .env | Config |
| **Assets 404** | Run `npm run production` | Optimization |
| **Permission denied** | chmod 755 storage/ | Deployment |
| **.htaccess not working** | Enable mod_rewrite at host | Troubleshooting |

## 💡 REMEMBER

- **Database host:** Always `localhost`
- **Database user:** Usually prefixed (e.g., `user_agans_user`)
- **Permissions:** storage/ = 755, .env = 644
- **HTTPS:** Free with Let's Encrypt (enabled in panel)
- **Email:** Use Gmail SMTP or hosting email
- **SSH:** Not available on Infinity Free (use FTP instead)
- **Debug:** Set APP_DEBUG=false in production
